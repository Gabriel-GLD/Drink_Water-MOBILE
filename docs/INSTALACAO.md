# Instalacao

## Pre-requisitos

- Node.js compativel com Expo
- Android Studio ou um dispositivo Android
- Git

## Dependencias

Na raiz do projeto:

```powershell
npm install
```

## Execucao

```powershell
npx expo start
```

Pressione `a` no terminal para abrir no Android ou utilize o QR Code em um
cliente compativel com os modulos usados pela versao atual.
